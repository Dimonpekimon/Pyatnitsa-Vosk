# Пятница 3.6

Голосовой ассистент для Windows, который живёт в фоне и отвечает на «Пятница, ...».
Распознавание речи и синтез голоса — локально, без облака и без GPU. Мозг —
бесплатный Gemini API. Интерфейс — прозрачное окно поверх рабочего стола.

```
Вы:     «Пятница, который час»
Пятница: «Сейчас 22:41, сэр.»        ← без «Да, сэр?» и без второй записи
Вы:     «а завтра что?»              ← уже без оклика: разговор продолжается
Пятница: «Завтра плюс одиннадцать, небольшой дождь.»
```

`Windows 10/11` · `Python 3.14` · `Vosk` · `Piper` · `Gemini 3.5 Flash` · `Electron 45`

---

## Коротко о главном

- **Слышит офлайн.** Vosk распознаёт фразу за 0.2–0.5 с на обычном CPU, интернет
  не нужен, звук никуда не уходит.
- **Говорит офлайн.** Piper синтезирует нейронный голос локально — не зависит от
  серверов Microsoft.
- **92 команды** и 1542 формулировки плюс свободный разговор через нейросеть. Понимает
  составные фразы: до трёх команд за раз.
- **Управляет компьютером:** громкость, яркость, окна, программы, питание,
  скриншоты, буфер обмена, напоминания, погода, калькулятор, OCR экрана.
- **Одно окно вместо консоли.** Полупрозрачная карточка с визуализатором,
  историей диалога и полем ввода.
- **Подсказывает, нужен ли оклик.** Маленькая метка в окне показывает, можно ли
  говорить прямо сейчас или нужно позвать «Пятница».
- **Запускается одним файлом** — `Пятница.exe` в корне проекта: двойной щелчок,
  без аргументов и без консоли.

## Экспериментально: мозг на Rust

В ветке `experimental` лежит `brain-rs` — LLM-слой, переписанный на Rust:
оба провайдера (Gemini и любой OpenAI-совместимый шлюз), цепочка запасных
моделей, история диалога, зрение, обход мёртвого прокси. Поведение и тексты
ошибок совпадают с `brain.py`, поэтому переключение — замена одного импорта:

```python
from brain_rs import Brain, BrainUnavailable   # вместо from brain import ...
```

```bash
cd brain-rs && cargo build --release   # ~4 МБ, нужен Rust 1.75+
python test_brain_rs.py                # 10 сквозных проверок без сети
```

Подробности, протокол моста и таблица соответствий — в
[`brain-rs/README.md`](brain-rs/README.md). Ветка экспериментальная:
по умолчанию приложение по-прежнему использует `brain.py`.

## Что нового в 3.6

Главное — обращение и команда больше не расходятся на два такта.

| Что | Было в 3.5 | В 3.6 |
|---|---|---|
| **«Пятница» + команда** | окно ожидания 0.9 с, и пауза «полсекунды» уже не попадала в него — звучало «Да, сэр?» поверх первых слов | окно 1.5 с: команда после обращения выполняется сразу, отклик — только если вы действительно молчите |
| **Обращение в любом месте** | снималось только с начала фразы | «который час, Пятница» и «слушай, Пятница, ...» тоже понимаются |
| **Падежи оклика** | «пятнице», «пятницей», «пятницо» не снимались | снимаются: окончание Vosk слышит вольно |
| **Команда одним словом** | «Пятница, погромче» терялась, если слова нет в реестре | уходит на выполнение или в нейросеть |
| **Сборка** | `Пятница.exe` собирался локально | готовый лаунчер лежит в репозитории и в релизе |
| **Автопроверки** | 439 | **473** |

### Как это звучит

```
Вы:     «Пятница»            ← и сразу, без паузы:
Вы:     «громче»
Пятница: «Сделал, сэр.»      ← «Да, сэр?» не прозвучало
```

А если действительно нужно подождать — «Пятница» … полторы секунды тишины —
тогда ассистент откликнется и начнёт слушать команду отдельно.

### Что нашла проверка после релиза

Сквозной прогон «синтез → Vosk → команда» по всем 1542 алиасам и живой запуск
ядра выявили четыре дефекта — все исправлены:

| Что было | Что стало |
|---|---|
| «Пятница, какая зарядка батареи» уходила в нейросеть: в реестре был «заряд батареи», но не «зарядка» и не «батарея» | `battery` понимает «батарея», «зарядка», «аккумулятор» и их падежи |
| «Какой у меня процессор», «сколько ядер», «какая видеокарта» — нейросеть, хотя железо под рукой | `system_info` отвечает процессором и числом ядер (реестр Windows), а не только памятью и диском |
| «Переведи 10 долларов в рубли» → «Назовите число и единицы» | конвертер считает валюты по курсу ЦБ: «10 долларов — это 805,57 рубля» |
| `npm run check:ui` не мог пройти никогда: скрипт дёргал старый мост `window.jarvis` и старые каналы `jarvis:*` после переименования | проверка проходит: окно монтируется, диалог открывается, click-through работает в обе стороны |

Плюс подсказка «скажи «Пятница»» в компактном виде просвечивала сквозь полосы
визуализатора и не читалась — теперь у пилюли плотный фон; а в текстовом режиме
она больше не показывается вовсе (микрофона там нет).

### Чем 3.x отличается от старых сборок

Нумерация начинается заново: **3.5 включает всё, что было сделано в 3.0–3.4**,
и закрывает главную проблему тех сборок — интерфейс, который не запускался.

| Что | Было раньше | Сейчас |
|---|---|---|
| **Распознавание речи** | `speech_recognition` + Google: интернет, отправка звука в облако, задержка | **Vosk** локально: 0.2–0.5 с, офлайн, модель 45 МБ, без GPU |
| **Голос** | `pyttsx3` (роботизированный SAPI), затем edge-tts — только с интернетом | **Piper** локально; edge-tts и SAPI остались резервом |
| **Мозг** | Ollama + Mistral 7B: несколько гигабайт, долгий ответ на слабом железе | **Gemini 3.5 Flash**: бесплатный тариф, ответ за 1–2 с, понимает картинки |
| **Интерфейс** | Консоль → веб-страница в браузере | **Настольное окно** Electron: всегда поверх, компактный вид и диалог |
| **Запуск окна** | Не поднималось без Node.js; падало на GPU-процессе | **Запускается всегда**: npm нужен только для пересборки, падение GPU обходится автоматически |
| **Повторный запуск** | Второй экземпляр дрался за микрофон | Показывает окно уже работающего ассистента |
| **Диагностика** | Любая ошибка Gemini = «ключ неверный» | Различает неверный ключ, лимит и блокировку региона |
| **Автопроверки** | 211 | **473** |

### Что именно исправлено в этой сборке

- **Окно запускается без Node.js.** `npm` требуется только для `npm install` и
  `npm run build`. Готовая сборка (`desktop/dist` + `electron.exe`) стартует
  сама, поэтому сломанный Node больше не «убивает» интерфейс.
- **Обход падения GPU-процесса Electron.** Сторонние DLL (антивирус, оверлей,
  драйвер) роняли окно за пару секунд. Теперь оно перезапускается с
  `--disable-gpu-sandbox`, а флаг запоминается в `data/overlay_flags.json`.
- **Повторный клик по ярлыку** не поднимает второй голосовой цикл — просто
  возвращает окно на экран.
- **Если окно не поднялось**, ассистент говорит об этом вслух: в фоновом режиме
  консоли нет, и раньше поломка выглядела как «приложение не запускается».
- **Понятная диагностика Gemini:** блокировка региона (`User location is not
  supported`) больше не выдаётся за неверный ключ — подсказка про VPN.
- **Ничего не пропадает молча.** Исключение в голосовом цикле больше не убивает
  процесс: оно пишется в `data/pyatnitsa.log` с трассировкой, и цикл продолжает
  слушать. Лаунчер ведёт свой журнал — `data/launcher.log`.

## Быстрый старт

**Самый короткий путь — готовый `Пятница.exe`.** Он уже лежит в корне проекта
(и приложен к [разделу Releases](https://github.com/Dimonpekimon/Pyatnitsa-Vosk/releases)):
двойной щелчок — и всё запущено. Лаунчер сам находит Python, поднимает ядро с
окном и сразу выходит; консоли не будет. Ярлык и аргументы не нужны.

Из исходников:

```bash
git clone https://github.com/Dimonpekimon/Pyatnitsa-Vosk.git
cd Pyatnitsa-Vosk
pip install -r requirements.txt
python main.py --check      # что установлено и чего не хватает
python main.py              # запуск: голос + настольное окно
```

Всё то же самое одной командой (пакеты, голос, сборка окна) — двойной щелчок по
**`install.bat`** или:

```bash
python install_dependencies.py          # поставить всё
python install_dependencies.py --check  # только отчёт, ничего не менять
python install_dependencies.py --models # ещё и скачать модель распознавания (226 МБ)
```

Дальше — ярлык, чтобы не открывать терминал:

```bash
python make_shortcut.py     # «Пятница» на рабочем столе, запуск без консоли
python build_exe.py         # пересобрать сам Пятница.exe (нужен PyInstaller)
```

`build_exe.py` упаковывает `launcher.py` в один exe без консоли и кладёт его в
корень проекта. Иконка — `assets/icon.ico`. Ярлык после этого указывает на
готовый лаунчер и никаких аргументов не передаёт.

**При первом запуске** скачиваются две модели: Vosk (~45 МБ) в `data/models` и
голос Piper (~63 МБ) в `data/voices`. Это разовая операция — потом распознавание
и озвучка работают полностью офлайн.

**Ключ Gemini** нужен только для свободных вопросов. Без него все 92 команды
работают, но на «объясни, почему небо голубое» ассистент честно скажет, что мозг
недоступен. Бесплатный ключ: [Google AI Studio](https://aistudio.google.com/apikey),
прописывается в `pyatnitsa_settings.json` → `GEMINI_API_KEY`.

**Если Google блокирует регион** (`User location is not supported`), мозг можно
перевести на любой OpenAI-совместимый шлюз — российские работают без VPN:

```json
{
  "LLM_PROVIDER": "openai",
  "LLM_API_BASE": "https://api.polza.ai/v1",
  "LLM_MODEL": "openai/gpt-5-mini",
  "LLM_API_KEY": "pza_..."
}
```

Белорусский [aiai.by](https://aiai.by) устроен так же и открывает Gemini без VPN —
например, `gemini-3.8-flash` (1M контекста, текст + картинки):

```json
{
  "LLM_PROVIDER": "openai",
  "LLM_API_BASE": "https://api.aiai.by/v1",
  "LLM_MODEL": "gemini-3.8-flash",
  "GEMINI_FALLBACK_MODELS": ["gemini-3.5-flash-lite"],
  "LLM_API_KEY": "sk-aiai-..."
}
```

Бесплатного тарифа у шлюза нет — списывается по факту (3.8 Flash: 3,22 BYN за
1M входных токенов, 16,11 BYN за 1M выходных; flash-lite дешевле втрое). Когда
баланс кончится, ассистент скажет «на счету шлюза нет средств» вместо падения.
Совсем без денег остаётся ключ Google AI Studio из `GEMINI_API_KEY`
(`LLM_PROVIDER: "gemini"`) — у него есть бесплатная квота.

Не знаете, чей ключ и какой адрес API? Спросите у скрипта — он перебирает
56 известных шлюзов и говорит, какой ключ принял, какие модели доступны и что
именно ответил сервис:

```bash
python llm_check.py sk-xxxxxxxx              # опознать ключ
python llm_check.py sk-xxxxxxxx --base https://api.polza.ai/v1   # проверить один шлюз
```

| **Компьютер** | «сведения о системе», «сколько места на диске», «заряд батареи», «какой у меня ip», «есть ли интернет», «спящий режим» |

У каждой команды — до нескольких десятков формулировок (всего 1542 синонима на
92 команды), падежи и порядок слов не важны: «открой телегу», «запусти телеграмм»
и «открой телеграм десктоп» — одна и та же команда.

Всё, что не совпало с командой, уходит в нейросеть — можно просто поговорить.
Полный список с пояснениями: **`Документы → Пятница — команды.txt`** (создаётся
скриптом `python make_commands_list.py`, который сверяется с реестром команд).

**Составные команды.** Одной фразой — до трёх действий, они выполнятся по
порядку: «сделай громче **и** напомни через 5 минут позвонить маме». Фраза
делится только если **каждая** часть — известная команда, поэтому «объясни
разницу между и или» целиком уйдёт в нейросеть.

**Скриншоты** складываются в `Документы → Скриншоты Пятницы`, снимаются все
экраны сразу. **Заметки** — в `data/notes.txt`, **напоминания** — в
`data/reminders.json` и переживают перезапуск.

## Как это устроено

```
        голос                                  окно
   ┌──────────────┐                    ┌───────────────────┐
   │ микрофон     │                    │ Electron + React  │
   │ Vosk → текст │                    │ визуализатор,     │
   └──────┬───────┘                    │ история, ввод     │
          │                            └─────────┬─────────┘
          ▼                                      │ HTTP / SSE
   ┌──────────────────────────────────────────────▼─────────┐
   │ pyatnitsa_core.py — ядро: разбор команд, диалог, состояние │
   ├──────────┬──────────┬──────────┬───────────┬────────────┤
   │ actions  │ tts      │ brain    │ scheduler │ vision     │
   │ система  │ Piper    │ Gemini   │ таймеры   │ скриншот   │
   │ кальк.   │ edge/SAPI│ картинки │ напоминания│ OCR       │
   └──────────┴──────────┴──────────┴───────────┴────────────┘
                              │
                    api.py: 127.0.0.1:8765
```

Python — мозг, микрофон и голос. Electron — только окно: он не знает команд и
ничего не решает, а получает состояние и события по HTTP/SSE с петлевого адреса.
Поэтому окно можно закрыть и открыть заново, не теряя диалог.

| Модуль | Задача |
|---|---|
| `main.py` | точка входа, CLI, диагностика `--check` |
| `pyatnitsa_core.py` | ядро: маршрутизация команд, голосовой цикл, состояние |
| `actions.py` | системные действия, калькулятор, поиск, погода, утилиты |
| `speech.py` | микрофон и Vosk |
| `tts.py` | озвучка: Piper → edge-tts → SAPI |
| `voices.py` | каталог голосов Piper, загрузка, выбор, замеры |
| `tone.py` | обработка тембра: эквалайзер и компрессор для готового WAV |
| `voice.py` | CLI: список голосов, переключение, тембр, проверка, образцы |
| `brain.py` | Gemini: диалог и анализ изображений |
| `scheduler.py` | таймеры и напоминания |
| `vision.py` | скриншоты, OCR, анализ экрана |
| `api.py` | API ядра для окна и Telegram |
| `overlay.py` | сборка и запуск настольного окна |
| `events.py` | шина событий «ядро → интерфейс» |
| `launcher.py` | содержимое `Пятница.exe`: поиск Python и запуск ядра |
| `desktop/` | Electron + TypeScript + React |

## Настольное окно

Прозрачная карточка поверх рабочего стола: компактный вид (320×168) со
столбиками-визуализатором или развёрнутый диалог (430×470) с историей и вводом.

| Действие | Как |
|---|---|
| Обычный / полупрозрачный режим | `Ctrl+Alt+J` |
| Компактный вид / диалог | `Ctrl+Alt+U` |
| Прервать речь | `Ctrl+Alt+Space` |
| Прервать или свернуть | `Esc` |
| Скрыть / показать | значок в трее |
| Закрыть только окно | крестик (ассистент продолжит слушать) |

Клики проходят сквозь прозрачные области: интерактивны только сама карточка в
режиме диалога и кнопки. Окно не отбирает фокус у активного приложения.

### Метка оклика

Главная причина, по которой ассистента приходилось звать дважды, — нельзя было
понять, нужен ли оклик прямо сейчас. Теперь в окне всегда видна маленькая метка
в двух состояниях, и она есть в обоих видах окна — и в компактном, и в диалоге:

```
○ скажи «Пятница»          ← сейчас нужен оклик
● без оклика · 8 с         ← идёт разговор, говорите сразу
```

В развёрнутом окне формулировка длиннее: «Сейчас нужен оклик: «Пятница, …» —
дальше можно без него» и «Можно без оклика — ещё 8 с. Говорите сразу».
Счётчик обновляется сам, поэтому видно, сколько секунд осталось.

Рядом с меткой — кнопка «?»: она раскрывает пять коротких правил, чтобы не
держать их в голове. Метка намеренно неяркая (в компактном виде — 62%
прозрачности) и не перекрывает визуализатор.

**Ярлык на рабочем столе** (`python make_shortcut.py`) указывает на собранный
`Пятница.exe` и не передаёт ему аргументов: лаунчер сам находит папку проекта и
Python. Консоли нет, лог пишется в `data/pyatnitsa.log`, журнал лаунчера — в
`data/launcher.log`. Повторный клик не поднимает второй экземпляр, а показывает
окно работающего. Полностью выключает всё команда «выключайся» (или «отключи
интерфейс») — она гасит голос, API и окно.

Сам лаунчер после старта выходит, а ядро живёт под `pythonw.exe` — так его и
видно в диспетчере задач (вкладка «Подробности»). Искать «Пятница.exe» там
бессмысленно: этот файл уже завершился.

Требования к окну: **Node.js 20+** — только если нужно пересобрать интерфейс
(`npm run build`). Для запуска готовой сборки Node не нужен.

## Голос

Основной движок — **Piper**: локальная нейросеть, офлайн. Пятница говорит
женским голосом **«Сова»** (`sova200`): это самый высокий и светлый из
доступных русских голосов — 218 Гц основного тона против 184 у «Ирины»,
229 слов в минуту, разборчивость 96% по распознаванию Vosk. Модель
скачивается автоматически в `data/voices`.

```bash
python voice.py                # что есть и что выбрано
python voice.py use sova200    # скачать (если нужно) и выбрать голосом
python voice.py use mari       # мягкий женский, с обработкой «бодрее»
python voice.py use irina      # официальный, ровный, но темнее
python voice.py tone brisk     # характер: off | soft | confident | brisk | auto
python voice.py test --play    # синтез пробной фразы + замеры, сразу послушать
python voice.py samples        # одинаковые фразы разными голосами в outputs/
```

Голос выбирается **именем**, а не путём к файлу: `PIPER_VOICE` в
`pyatnitsa_settings.json`. Из имени выводятся файл модели, адрес загрузки,
рекомендуемый темп, поправка громкости и профиль обработки тембра, поэтому
`PIPER_MODEL` оставлен пустым (пустое значение = «по имени голоса»).
Запущенная Пятница подхватывает смену голоса к следующей фразе — перезапуск
не нужен.

| Голос | Пол | Тон | Темп | Тембр | Источник |
|---|---|---|---|---|---|
| `sova200` | женский | 218 Гц | 1.0 | — | сообщество (~20 мин речи) |
| `kat580` | женский | 187 Гц | 1.0 | — | сообщество (~20 мин речи) |
| `irina` | женский | 184 Гц | 1.2 | — | RHVoice (официальный) |
| `mari` | женский | 178 → 200 Гц | 1.35 | `brisk` | сообщество (~20 мин речи) |
| `dmitri` | мужской | 178 Гц | 1.0 | — | voice-datasets (CC0) |
| `denis` | мужской | 138 Гц | 1.0 | — | voice-datasets (CC0) |
| `ruslan` | мужской | — | 1.0 | — | RUSLAN corpus |

Женских голосов в официальном каталоге Piper ровно один — `irina`. Остальные
женские варианты взяты из репозитория сообщества `rraaww/ru_piper`: они обучены
на 20–40 минутах речи, поэтому в интонации возможны шероховатости, зато тембр
заметно выше и светлее. Разборчивость по распознаванию Vosk держится в
диапазоне 85–97% у всех четырёх; «Катя» иногда добавляет лишние слова.
Точные цифры текущего прогона — в `outputs/voice-samples/женские-голоса.html`:
разброс между прогонами синтеза около ±5%, так что запоминать их бессмысленно.

Темп подобран не на слух: `irina` при 1.0 звучит 8.8 с против 5.9 с у `dmitri`
на одной фразе, то есть на 52% медленнее, поэтому у неё темп 1.2 (Vosk держит
разборчивость до 1.6). Громкость голосов выровнена: модели нормализованы по
пику, но «Сова» при этом на 3.7 дБ громче «Ирины», и без поправки переключение
звучало бы как «стало громче». Поправка (`gain` в каталоге) умножается на
`PIPER_VOLUME`, а не заменяет её. Тембр можно подкрутить через
`PIPER_NOISE_SCALE` и `PIPER_NOISE_W` (`null` — значения из модели).

### Тембр: обработка после синтеза

Некоторые голоса звучат вяло не из-за модели, а из-за баланса спектра.
«Мари» — ровно такой случай: приятный мягкий тембр, но яркость всего 630 Гц
против 1647 у «Совы», и фраза читается как «из-за стены». Лечится не только
темпом (1.35), но и обработкой в `tone.py` — три фильтра RBJ (низкая полка,
пик присутствия, высокая полка), компрессор и подъём тона:

| Профиль | Что делает | Тон | Яркость | Присутствие | Воздух |
|---|---|---|---|---|---|
| `off` | ничего, как отдала модель | 183 Гц | 628 Гц | −12.2 дБ | −16.8 дБ |
| `soft` | −3 дБ ниже 180 Гц, +3 дБ на 2.5 кГц, +2.5 дБ выше 6 кГц | 183 Гц | 730 Гц | −10.3 дБ | −15.2 дБ |
| `confident` | то же, но сильнее, плюс компрессор 2.2:1 | 186 Гц | 1369 Гц | −6.6 дБ | −8.2 дБ |
| `brisk` | `confident` + тон ×1.10 + компрессор резче (2.6:1) | 201 Гц | 1415 Гц | −5.7 дБ | −8.2 дБ |

Цифры — один из прогонов на трёх фразах при темпе 1.35 (долговременный средний
спектр); между прогонами они гуляют примерно на ±5%, точные значения текущего
прогона — на странице образцов. Компрессор даёт основной эффект по яркости:
подтягивает тихие согласные, из-за чего речь становится разборчивее и
собраннее. Он смотрит вперёд на 2 мс — больше нельзя, иначе под опущенное
усиление попадает первый согласный и «пробки» слышится как «на садовом».
Разборчивость при обработке не падает: на одних и тех же исходных файлах WER
у всех профилей держится в пределах 5–10% (по 10 фразам).

**Подъём тона** (`"pitch"` в профиле) — пересчёт отсчётов: голос становится выше
и короче, а `voices.length_scale()` заранее растягивает синтез ровно на столько
же. Темп и высота остаются независимыми: `brisk` звучит выше, но не быстрее
`confident` при том же `PIPER_SPEED`. Пределы 0.8–1.35 — за ними голос звучит
«из бочки» или по-мультяшному.

Темп выше 1.35 для «Мари» уже вредит: на 1.42 WER вырос с 8.6% до 15.5%,
поэтому 1.35 — потолок, а не вкусовщина.

Громкость обработка **не меняет**: уровень восстанавливается по RMS, поэтому
`PIPER_VOLUME` и `gain` продолжают работать как раньше. Кэш озвучки при смене
профиля очищается сам — рядом с ним лежит подпись профиля.

Профиль задаётся в каталоге (`"tone": "brisk"` у «Мари») или настройкой
`PIPER_TONE`: `""` — «как задумано для голоса», `off` — без обработки.
Варианты «Мари» можно послушать в `outputs/voice-samples/мари-варианты/`.

Резерв: **edge-tts** (нейронные голоса Microsoft, нужен интернет) → **SAPI**
(системный голос, всегда доступен). Порядок задаётся `TTS_ENGINE`:
`piper`, `edge`, `sapi`, `auto`.

Синтезированные фразы кэшируются в `data/tts_cache` — повторная фраза звучит
мгновенно. Прерванный синтез не портит кэш: файл пишется как `.part` и
подменяется атомарно.

**Свой голос (дообучение).** Все русские модели Piper — это файнтюн с
английского `lessac` (так указано в MODEL_CARD каждой модели), то есть
дообучение — штатный путь. Но он требует датасета именно того голоса: 30–60
минут чистой речи с расшифровкой в формате LJSpeech (`wavs/` + `metadata.csv`),
плюс `piper_train`, PyTorch с CUDA и несколько часов на GPU. Датасета «голоса
Пятницы» не существует, а обучение на чужом корпусе воспроизведёт чужой голос —
поэтому по умолчанию стоят готовые модели из каталога, а не собственная тренировка.

**Голосовое общение.** Слово-активатор — «Пятница» (список в `WAKE_WORDS`).
Обращение снимается из любого места фразы, а не только с начала: «Пятница,
который час», «который час, Пятница» и «слушай, Пятница, время» — одно и то же.
Первая фраза произносится целиком и обрабатывается сразу, без второй записи и
без отклика.

Если прозвучало только обращение, ассистент не спешит говорить «Да, сэр?»: он
сначала `WAKE_JOIN_SEC` секунд (по умолчанию 1.5) слушает команду. Заговорили
без паузы — команда выполняется сразу; промолчали — звучит отклик и начинается
запись. Раньше отклик звучал поверх первых слов, и фразу приходилось повторять —
именно из-за этого казалось, что «нужно говорить по два раза».

Оклик понимается и в падежах, которых нет в списке: «пятнице», «пятницей»,
«пятницо» — Vosk слышит окончания вольно, и сравнивать нужно по основе. А одно
слово после обращения («Пятница, погромче») считается командой, даже если его
нет в реестре алиасов: человек уже позвал ассистента, значит говорил он, а не
комната.

**Прощания не выключают посреди фразы.** «Пока», «спать» и «бай» понимаются
только как отдельная фраза: «я хочу спать» или «пока не знаю» — обычный вопрос,
а не команда выключения. Живая речь при этом не страдает: «иди спать», «бай бай»,
«ну пока», «ладно пока» работают как прощание.

**Разговор без повторного оклика.** После ответа открывается окно на
`DIALOG_FOLLOW_UP_SEC` (по умолчанию 12 секунд): продолжение понимается молча,
без «Пятница».

```
Вы:     «Пятница, какая сегодня погода»
Пятница: «В Москве плюс восемь, облачно, сэр.»
Вы:     «а завтра?»            ← оклик не нужен
Пятница: «Завтра плюс одиннадцать, небольшой дождь.»
```

Как только в комнате стало тихо, окно закрывается и снова нужно обращение —
поэтому ассистент не реагирует на чужие разговоры. Сказать «хватит»
(«достаточно», «отбой») — закрыть разговор сразу. Отключается через
`DIALOG_MODE: false`; длина окна — `DIALOG_FOLLOW_UP_SEC`, ограничение числа
реплик подряд — `DIALOG_MAX_TURNS`. Полностью без слова-активатора —
`WAKE_WORD_REQUIRED: false` или `--no-wake`.

**Падежи и окончания не важны.** Команду можно произнести в любой форме:
«закрой окна», «закрою окна», «выключи интерфейса», «прибавь громкости»,
«запусти роблокс студию». Слова сравниваются по основе (`utils.stem_ru`),
поэтому одна и та же команда узнаётся в десятке вариантов. Правило при этом
строгое: команда срабатывает, только если **все** слова фразы объясняются
синонимом (вежливые вставки вроде «пожалуйста» не мешают). «Закрой дверь» или
«включи свет» по-прежнему уходят модели, а не в «закрой окно» и «включи звук».

```json
{
  "VOSK_MODEL_NAME": "vosk-model-ru-0.42",

}
```

Windows (`Windows.Media.Ocr`), ничего скачивать не нужно; русский поддерживается
при установленном языковом пакете. «Что на экране» / «проанализируй экран»
отправляют снимок в Gemini (крупные картинки сжимаются автоматически).

## Проверка

```bash
python main.py --check     # окружение, модели, ключ, окно
python selftest.py         # 473 проверки логики, ничего в системе не меняет
```

Селфтест проверяет калькулятор и разбор времени, приоритеты и составные команды,
голосовой цикл, приветствие, выключение с подписчиками, шину событий, API ядра,
полноту списка команд и то, что **у каждой команды реестра есть обработчик**
(именно эта проверка ловит «команда объявлена, а метода нет»). Отдельные тесты:
`test_scheduler.py`, `test_tts.py`, `test_telegram.py`, `test_api.py`,
`test_utils_regression.py`.

## Решение проблем

**Двойной клик по `Пятница.exe` ничего не делает.** Загляните в
`data/launcher.log`: там записан каждый шаг — какая папка проекта найдена, какой
интерпретатор пробовался, с каким кодом завершился процесс. Типичные причины:
exe лежит не рядом с `main.py`; не установлен Python; сломаны зависимости
(лечится `install.bat`). Лаунчер специально ждёт три секунды после запуска: если
процесс упал на старте, вы увидите окно с ошибкой, а не тишину.

**Окно не появилось.** Смотрите `data/pyatnitsa.log` — там причина. Если написано
`npm не найден`, а окно нужно пересобрать, поставьте Node.js 20+ (для запуска
готовой сборки он не нужен). Если окно падает за пару секунд с кодом
`2147483651` — это падение GPU-процесса; ассистент обходит его сам через
`--disable-gpu-sandbox`. Диагностика: `python main.py --check`.

**«Открой телеграм», а ничего не происходит.** У мессенджеров теперь есть
свои команды, и программа ищется тремя способами: по известным путям установки
(`%APPDATA%\Telegram Desktop`, `%LOCALAPPDATA%\Discord`), по ярлыку в меню
«Пуск» (русское название переводится в латинское: телеграм → Telegram) и через
протокол `tg://` для версии из Microsoft Store. Если Telegram не найден вообще,
ассистент честно скажет об этом и откроет веб-версию. Остальные программы
запускаются командой «открой приложение <название>».

**«Ключ Gemini неверный» / «Нет связи с Gemini».** Проверьте `GEMINI_API_KEY`,
интернет и прокси. Отдельное сообщение про **регион** означает, что Google
блокирует вашу сеть: ключ рабочий, нужен VPN или прокси. Команды при этом
работают, свободные вопросы — нет.

**«Бесплатный лимит Gemini исчерпан».** Подождите минуту или переключитесь на
`gemini-3.5-flash-lite` — у неё отдельная квота.

**Микрофон не слышит.** Параметры → Конфиденциальность → Микрофон. Список
устройств: `python -c "import sounddevice; print(sounddevice.query_devices())"`.

**Пятница срабатывает сама.** Увеличьте `VAD_RMS_THRESHOLD` (например, до `0.02`)
или перезапустите — калибровка микрофона идёт при каждом старте.

**Голос не звучит.** Проверьте модель:
`python -c "from tts import piper_model_ready; print(piper_model_ready())"`.
Нет модели — `python download_voices.py`. Крайний случай: `"TTS_ENGINE": "sapi"`.

**Модель Vosk не скачалась.** Скачайте архив
`vosk-model-small-ru-0.22.zip` с [alphacephei.com](https://alphacephei.com/vosk/models),
распакуйте в `data/models` и запустите снова.
